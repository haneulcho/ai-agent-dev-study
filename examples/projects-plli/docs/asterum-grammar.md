# 아스테룸 문자 해석 규칙

## 기준 자산

아스테룸 기본 문자는 `assets/asterum/characters/svg`의 자음 14개와 모음 14개다. 문자와 한글 자모의 대응은 `assets/asterum/mapping/asterum.mapping.v1.json`이 단일 기준이다.

SVG 파일명은 원본을 사람이 검토하기 위한 정보일 뿐이다. 서비스와 학습 파이프라인은 파일명을 해석하지 않고 매핑의 `glyph_id`와 `ko_jamo`를 사용한다.

## 해석 순서

1. 사진에서 텍스트 영역과 문자 영역을 찾는다.
2. 문자를 읽기 순서대로 정렬한다.
3. 각 문자 이미지를 28개 `glyph_id` 중 하나로 분류한다.
4. `glyph_id`를 한글 호환 자모로 변환한다.
5. 자모 열을 초성·중성·종성 규칙으로 음절 조합한다.

예를 들어 `ㄱ ㅑ ㅇ ㅗ ㅐ`는 `ㄱ+ㅑ`, `ㅇ+ㅗ+ㅐ`로 나뉜다. `ㅗ+ㅐ`는 복합 모음 `ㅙ`가 되므로 결과는 `갸왜`다.

현재 조합기는 한글의 7개 복합 모음과 11개 겹받침을 결정적으로 처리한다. 초성이나 중성이 없는 불완전한 열은 임의로 보정하지 않고 위치와 오류 코드를 반환한다.

## 아직 정해야 하는 규칙

- 실제 사진에서 단어·음절·문자 간격을 구분하는 기준
- 줄바꿈과 문장부호를 보존하는 방식
- 띄어쓰기가 없거나 문자끼리 닿은 경우의 후보 선택 방식
- 영문 결과를 위한 승인된 매핑 또는 로마자 표기 규칙

이 항목은 실제 문장 이미지 샘플을 확인한 뒤 테스트 사례와 함께 확정한다. 생성형 AI나 한국어 사전으로 인식 결과를 자동 보정하지 않는다.
