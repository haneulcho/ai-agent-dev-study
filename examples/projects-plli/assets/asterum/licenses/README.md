# 아스테룸 자산 권리 확인

## 현재 상태

- `characters/svg/*.svg`: 사용자가 직접 제작한 28개 기본 문자 원본
- 로컬 실습, 합성 데이터 생성, OCR 모델 학습: 허용
- 현재 `ai-agent-dev-study` 공개 저장소 포함: 사용자의 commit·push 요청으로 허용
- 제3자의 재배포·재라이선스와 운영 서비스 배포: 별도 확인 필요

프로젝트 소스 코드의 MIT 라이선스가 SVG 자산의 일반 재배포 권한까지 자동으로 의미하지 않는다. 운영 서비스 배포나 외부 프로젝트 재사용 전에는 제작자의 허용 범위를 이 문서에 추가한다.
